# v2.4.2 更新与升级

本版本完成 Issue #152 的 Go 小妲助手升级。应用与 WebUI 版本统一为 **2.4.2**。

## 用户可见变化

- **积分签到**：已启用助手的讨论群中发送“签到”，每日一次，随机获得 0.1～5.0 永久积分；免费次数耗尽后，每条接纳消息扣 1.0 积分。
- **必订阅频道**：支持多个频道且要求全部加入，提供加入按钮、重新验证与助手权限诊断。
- **评论区助手**：按频道启用和配置唤醒词，保留用户完整原文，利用原帖与全部已收集评论回答。
- **并发与追问**：AI 不再阻塞 Update 分发；同一作用域追问进入同一活动回合，保留工具结果，统一输出。
- **原生富文本**：私聊 Draft 预览、群组同消息编辑、typing 刷新，支持标题、表格、引用、代码和链接。
- **WebUI**：新增“小妲助手”配置卡片，使用现有 Google 浅色与 X 深色设计令牌；高级设置和历史回溯收纳在折叠区。

## 升级步骤

1. 备份现有 `data/config.json`、环境配置和 MySQL 数据。
2. 更新应用及 Go 助手二进制，确认 `QA_BOT_RUNTIME=go`，不要并行运行旧 Python 助手。
3. 启动后会幂等创建积分、签到、流水、消息预留、全站用量、帖子映射与评论表；不删除既有配额和会话数据。
4. 默认沿用 UTC 日界线。需要调整时区时，在“AI 配置 → 小妲助手”中选择业务时区；已预留消息的退款仍绑定原日期。
5. 如需启用订阅或评论区，配置对应频道，运行“检查助手权限”并保存。
6. 如需补充接入前评论，可通过已登录 UserBot 回溯指定帖子。Bot API 本身不会自动补齐历史。

频道、唤醒词、订阅开关、签到和时区热生效；执行并发、队列和回合限制在重启助手后生效。

## 计费与数据边界

消息使用 `chat_id + message_id` 幂等预留。重复 Update 不会重复扣费，失败／取消逐条退款；重启时恢复遗留预留。积分消息不能绕过全站上限。

评论上下文明确标注为已收集快照，不承诺包含已删除或账号不可见的消息。不同帖子、不同用户的个人会话独立，公共评论不冒充个人追问。

`/clear` 清除当前作用域并取消活动回合，旧生成结果不能回写；其他作用域不受影响。
