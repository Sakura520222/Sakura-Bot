# WebUI 管理面板

WebUI 将频道、总结、互动、转发、AI、Sakura Guard、Sakura Wiki 和系统设置集中在浏览器中。Go 主进程提供管理 API 与已构建的 Vue 页面。

## 开启和访问

在 `data/.env` 中启用 `WEBUI_ENABLED=true`，正式环境设置 `WEBUI_DEV_MODE=false`。容器端口默认 8080，可通过 Compose 根目录环境或宿主机变量配置外部 `WEBUI_PORT` 和 `WEBUI_CONTAINER_PORT`。打开对应地址的 `/login`。安装步骤见[快速开始](User-Getting-Started.md)。

`/api/health` 用于检查 HTTP 服务。登录后再核对主 Bot、助手、UserBot 和所需频道的业务状态。

## 登录与权限

管理员登录码由主 Bot Token 去掉首尾空白后计算 SHA-256，并取十六进制结果的前 16 位。使用该值登录管理页。请在受信任的部署终端中计算，避免将主 Bot Token 或管理登录码写入日志与公开文档。

公开 Wiki、Wiki 账号和 WebUI 管理员属于不同权限范围。公开访客能看到已发布且公开的 Wiki 内容，管理端使用管理员会话执行配置、任务与发布操作。

### 频道总结

在 **频道管理** 的频道行点击「生成总结」。页面收到任务编号后轮询状态，期间该行按钮显示等待状态。关闭页面不会立即取消后台任务。再次提交同一频道时，如果已有 WebUI 总结在运行，服务端复用当前任务。主进程停止时尚未完成的任务会结束。

页面显示失败原因，服务器记录任务开始、结束或失败和任务编号。若显示「没有新消息需要总结」，系统已读取该频道并核对过总结窗口。模型超时、识图排队和 Telegram 权限属于不同环节，按页面反馈及日志定位。

## AI 与图片

通过 **AI 配置 → AI 厂商、模型与用途** 绑定用途。频道总结、助手、图片识别、投票、Wiki 生成、Wiki 审校、Guard 判定和 Guard 图片判定可以独立选择模型和思考等级。详情见[模型和用途路由](AI_PROFILES.md)。

启用「频道图片 OCR / 描述」可让频道总结、图片投票和检索引用保存的识别内容。助手私聊收图依据「助手问答」所选模型的图片能力。详情见[频道图片采集与识别](images-pipeline.md)。

## 系统与配置保存

系统页可查看主 Bot 运行与调度状态，管理独立助手进程的启动、停止或重启。助手使用 Go。切换业务配置时，以页面的保存结果为准，注意执行并发、队列容量等设置的生效条件。

配置写入使用版本检查和原子落盘。遇到版本冲突时重新加载，按服务器当前值合并本地修改。模型 API Key 留空表示保留已保存值，清除密钥需明确选择清除。详见[配置持久化与恢复](Developer-Configuration-Persistence.md)。

## 排查

- 页面无法打开时检查容器健康、外部端口映射以及反向代理转发。
- 能打开登录页但无法加载数据时，重新登录并检查管理员权限和后端日志。
- Wiki 任务的「已接收」计入思考和正文，「正文」只计模型返回的可见文本。最终 Token 用量来自结束时的响应。详见 [Wiki 增量任务](User-Sakura-Wiki.md#增量索引与任务恢复)。
